# Standard — Database migrations (Alembic)

Source of truth for schema migrations on async SQLAlchemy 2.0 + Alembic. Complements
`standards/backend-fastapi.md` (models) and is scaffolded by the `alembic-migration` skill.

## Principles

- **Autogenerate, then mandatory manual review.** Never trust the generated script blindly — it
  misses data migrations, enum changes, server defaults and unsafe transitions.
- **One logical change per migration**, with a clean `revision`/`down_revision` chain (no
  branches).
- **Reversible**: every migration has a working `downgrade()` unless truly impossible — then say
  so explicitly in the script.
- **No silent data loss**: dropping a column/table or a destructive backfill is an explicit,
  called-out decision.
- **Stay async**: keep the project's existing async migration setup; do not switch to sync.

## Review checklist (the autogenerated script)

Walk the diff before committing:
- detected ops vs your actual intent (no spurious drops/creates from metadata drift);
- server defaults, enum value changes, index/constraint **names**;
- nullable → not-null transitions on **populated** tables (needs a backfill first);
- foreign-key creation order and cascade rules;
- large backfills **batched**, not one giant `UPDATE`.

## Workflow

1. Read the model change and the history (`alembic history`).
2. `alembic revision --autogenerate -m "<intent>"`.
3. **Review** the script against the checklist above; fix it by hand (data migrations, batched
   backfills, safe nullable→not-null in steps).
4. Validate on a dev DB: `alembic upgrade head` → `alembic downgrade -1` → upgrade again.
5. Summarize: revision id, ops performed, reversibility, risks, any required data step.

## Rules

1. Autogenerate is a **draft**, never the final script.
2. Test both directions (`upgrade` **and** `downgrade`) on a dev DB before sharing.
3. Sensitive migrations (drops, PII columns, large backfills) → flag for `security-reviewer`
   before they run anywhere shared.
4. Keep migrations in sync with the models they reflect (`standards/backend-fastapi.md`).
